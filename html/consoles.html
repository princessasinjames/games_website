Consoles

This is the webpage for listing consoles that support the games on the Home page. This webpage will discuss where you can normally play Animal Crossing (New Horizons), Fall Guys, Stardew Valley, Solitaire, and Minecraft.

List of Consoles:

  1. Nintendo Switch
  2. macOS
  3. Windows
  4. Xbox

Figure 1: free use image from pexels.

1. Nintendo Switch

On a Nintendo Switch, you can play:
1. Stardew Valley
2. Animal Crossing (New Horizons)
3. Fall Guys
4. Minecraft
5. Solitaire

Figure 2: free use image from pexels.

2. macOS

On macOS, you can play:
1. Stardew Valley
2. Fall Guys
3. Minecraft (Java)
4. Solitaire

Figure 3: free use image from pexels.

3. Windows

On a Windows computer, you can play:
1. Stardew Valley
2. Fall Guys
3. Minecraft (Java & Bedrock)
4. Solitaire

Figure 4: free use image from pexels.

3. Xbox

On an Xbox, you can play:
1. Stardew Valley
2. Fall Guys
3. Minecraft
4. Solitaire
